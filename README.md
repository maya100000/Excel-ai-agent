# 🤖 Excel AI Agent – Business Data Automation

🚀 **Live Demo:** [Open the App](https://excel-ai-agent-bwdzp4vdxhjshykzqg9pjw.streamlit.app/)

---

## 📌 Overview

An intelligent AI-powered agent that transforms raw Excel data into actionable business insights.

This system goes beyond traditional analysis — it **understands, cleans, analyzes, and actively operates on business data**.

It is designed to simulate a real-world **business analyst / operations assistant** working directly on Excel files.

---

## 🧠 What This Agent Does

- 📂 Reads Excel files (multi-sheet support)
- 🌍 Translates Hebrew data into English
- 🧹 Cleans and standardizes messy data
- 📊 Computes KPIs and business metrics
- ⚠️ Detects anomalies and performance issues
- 📈 Analyzes agent / employee performance
- 📄 Generates structured summaries and new Excel outputs

---

## ▶️ How to Use

1. Upload an Excel file
2. The agent will automatically:
   - Translate schema (Hebrew → English)
   - Clean and normalize the data
   - Analyze KPIs and performance
   - Detect anomalies

3. Download the processed file and summary

💡 Example commands:

- "Analyze this dataset"
- "Compare this month to last month"
- "Show underperforming agents"
- "Highlight anomalies"
- "Generate an executive summary"

## ⚙️ Key Features

### 📂 Data Processing

- Automatic schema detection
- Handles inconsistent structures
- Supports multiple sheets

### 🌍 Translation Layer

- Hebrew → English column mapping
- Normalized internal schema

### 🧹 Data Cleaning

- Remove duplicates
- Handle missing values
- Standardize formats (dates, numbers, etc.)

### 📊 Business Analysis

- Time-based comparisons
- Performance analysis

### ⚠️ Anomaly Detection

- Identifies unusual patterns
- Highlights outliers and issues

### 📄 Output Generation

- Summary sheets

- Business insights in natural language
